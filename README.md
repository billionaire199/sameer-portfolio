# Sameer Ahmed — IT Support / System Administrator Portfolio

A responsive, single-page cyber-inspired portfolio built with plain HTML, CSS and JavaScript. No build step or paid service is required.

## Run locally

1. Extract the ZIP (if using the ZIP download).
2. Open `index.html` in a browser. For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com.
2. Create a public repository named `sameer-portfolio`.
3. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the deployment. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/sameer-portfolio/`.

Alternative: import the GitHub repository into https://vercel.com and deploy. Vercel provides a free URL ending in `vercel.app` for eligible personal use.

## Personalise before publishing

- Confirm the experience timeline and add verified employer names, job titles and dates. The current experience section intentionally avoids guessing where the supplied work history had conflicting dates.
- Add your LinkedIn URL and phone number if you want them public.
- Add a PDF resume and a download link if desired. No resume file has been bundled in this starter.
- Review all skills and project descriptions so they accurately represent your work.
- The email link currently uses `sameerahmedshaik9@gmail.com`; change it in `index.html` if needed.
